fun session(context: Context, tenantId: String, formId: String? = null, environment: String, authHandler: VgsAuthHandler? = null, onSuccess: (instance: VGSCollect) -> Unit, onError: (code: Int, message: String?) -> Unit)

Asynchronously creates and initializes a VGSCollect instance.

Parameters

context

activity context.

tenantId

unique vault identifier.

formId

optional form identifier. If null or blank, VGSCollect is returned without session-based card attributes support.

environment

target environment (e.g. sandbox, live).

authHandler

provider responsible for supplying an auth token (required only when formId is provided).

onSuccess

called with a fully initialized VGSCollect instance.

onError

called if initialization fails.
